# Print V3 candidate — lightweight 410 mm

- [Full left-hand wand, raised buttons](Print-3-full-left-raised-buttons-410mm.3mf): new hollow grip and complete matching parts.
- [Upper replacement only](Print-3-upper-only-410mm.3mf): retain the printed V2 handle and bottom cap.
- [Compact button fit trial](Print-3-compact-button-fit-test.3mf).
- [Slim bayonet fit trial](Print-3-slim-bayonet-fit-test.3mf).
- [Editable CAD, assembly and verification guide](../magic-wand/hardware/printed-loop-wand/v3/README.md).
- [Interactive comparison](../magic-wand/hardware/printed-loop-wand/v3/preview/index.html), served through a local repository HTTP server.

The two lower shafts fit different handle heights. The full revision uses a 160 mm grip; the upper-only version mates to the existing 140 mm V2 grip. Both end at 410 mm. Original V2 files are preserved.

PETG slicer estimates: upper set 40.09 g versus 49.42 g for V2; new left grip 47.11 g versus 76.89 g. The complete new left set is about 90.71 g, including supports/brims and three compact inserts/keepers. These are estimates, not weighed prints. The compact insert's side orientation removes its prior floating-cantilever warning. The handle uses normal supports instead of tree supports to keep branches out of its hollow passages. No unsupported-overhang or floating-cantilever warning remains in the final prepared slices; printed PETG fit and flex still need the small trials. Battery fit remains provisional.

No printing has been started. Select the actual printer and PETG filament before using a prepared project. The projects were sliced for P1S 0.4 mm, 0.2 mm layers, three walls and 20% infill; internal voids are explicitly hollow in the CAD.
