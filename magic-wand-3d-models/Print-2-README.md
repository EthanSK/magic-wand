# Wand Print V2

The V2 wand is the **340 mm diamond mug wand**, with mirrored grips, separate Choc button mounts, a clipped XIAO Sense cradle and bottom battery access.

- [Full V2 Bambu project](Print-2-diamond-mug-wand.3mf) — fourteen instances: two grip choices and one shared set of remaining parts. Choose one grip for a working wand; slice before printing.
- [Head and clip fit test](Print-2-diamond-head-fit-test.3mf) — check the board/clip before the full print.
- [Editable CAD, preview and assembly instructions](../magic-wand/hardware/printed-loop-wand/v2/README.md).
- [Source and export release record](Print-2-diamond-mug-wand.json).

Use **Download raw file** on GitHub for a 3MF. The earlier print files and Print 1 baseline remain unchanged. Print V2 is independent of firmware control-version names. Physical fit and strength are still unverified; battery dimensions remain provisional.
