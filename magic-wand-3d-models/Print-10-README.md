# Print V10 — solid spiral body with separate slots, detachable loop, both hands

[Complete prepared Bambu project](Print-10-complete-left-right-top-slide-410mm.3mf): 12 actual build instances, both handed stems, a universal loop and a shared set of remaining parts. Choose one stem for a working wand. The [one-left-wand file](Print-10-one-left-wand-410mm.3mf) contains 11 instances.

The supporting tube and full original raised helix strips remain continuous. Nineteen separate narrow slots avoid the spirals and three longitudinal supporting lands. Four long rounded loop slots replace the little bores. The rejected open braid is not used. The corrected upper/thumb region protrudes farther; loop orientation and button angles stay unchanged.

The loop detaches using an integrated side tab and 22 mm upward slide through captured dovetails. Battery, buttons and wiring stay in the stem. [Print the loop-mount coupon first](Print-10-detachable-loop-fit-test.3mf).

One left wand estimates **76.072 g printed PETG with the loop; 65.902 g without**. This is 0.251 g above V8 with its fixed loop: new attachment mounts offset the slot savings. Hardware is unweighed. The six reference slices have no object warnings. Physical strength, spring force/life, comfort and assembled weight need testing.
