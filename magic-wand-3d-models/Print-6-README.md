# Print V6 candidate — side-button pair raised

Both side buttons move **up 14 mm** from V5. The upper side centre is **125 mm** from the base, just **4 mm below** the unchanged thumb at 129 mm. The lower side centre is **99 mm**. The pair retains its **26 mm spacing**. Side angles, radial position, thumb location, sliding fittings and all other mechanical features remain unchanged.

- [Complete project, both handed grips](Print-6-complete-left-right-top-slide-410mm.3mf): eleven instances, two grip choices plus shared parts.
- [One complete left wand](Print-6-one-left-wand-410mm.3mf): ten instances.
- [Upper replacement for an existing V2 grip](Print-6-upper-only-helix-410mm.3mf): existing button positions stay unchanged on that retained physical grip.
- [Button fit coupon](Print-6-top-slide-button-fit-test.3mf) and [shaft-joint coupon](Print-6-slim-bayonet-fit-test.3mf): their geometry is unchanged from V5.
- [Editable CAD and assembly instructions](../magic-wand/hardware/printed-loop-wand/v6/README.md).
- [Interactive model](../magic-wand/hardware/printed-loop-wand/v6/preview/index.html), served through a repository HTTP server. Select **Raised buttons** and Left/Right hand.

Only the two new handed grip meshes change; all thirteen other exported meshes match V5 exactly. Existing shafts, head, battery parts and thin sliding plates remain compatible. Previous versions are preserved. Physical comfort still needs user acceptance; clearance and slice checks are not a physical fit test.
