# Print V11 — open ribbed shell, both hands

[Complete project: both handed stems plus shared remaining parts](Print-11-complete-left-right-top-slide-410mm.3mf) · [one left wand](Print-11-one-left-wand-410mm.3mf) · [editable CAD and full guide](../magic-wand/hardware/printed-loop-wand/v11/README.md)

Larger curved hexagonal windows replace the sparse V10 slots. Four continuous axial rails, full raised spiral strips and short cell connections remain. The detachable loop has larger inner/outer and broad-face openings. Length, taper, controls, battery/wire routes, both handed stems and all mating joints are retained.

One left wand estimates **70.754 g printed PETG**, **5.318 g (6.99%) less than V10**; supports/brim add 3.953 g. Hardware is unweighed, so the complete 80/100 g target is not verified. All six prepared projects slice without reported warnings; closed-mesh, interface, layer and protected-path checks do not establish physical strength or fit. Test the [small loop interface](Print-11-detachable-loop-fit-test.3mf), [switch plate](Print-11-top-slide-button-fit-test.3mf) and [bayonet](Print-11-slim-bayonet-fit-test.3mf) first.

The [upper-only replacement](Print-11-upper-only-helix-410mm.3mf) is for a retained V2 grip. The complete plate contains both handed stems with one shared set of other pieces; choose one stem. Previous releases remain unchanged.
