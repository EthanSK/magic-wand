Magic Wand

Mouse, HUD, scrolling and speech to text from three buttons on a wand.

Turning the wand moves my Mac’s pointer or the Agentic Mouse HUD outline. A Puck.js at the tip reads the rotation and sends it over Bluetooth.

How It Works

  1. Puck.js

    Espruino JavaScript on the wand reads the gyro and buttons, filters the motion and decides each gesture.

  2. Bluetooth

    Short text reports travel over the Puck’s Bluetooth UART link: pointer moves, HUD angles, scrolling and button edges.

  3. Wand Receiver

    A background Mac app posts ordinary pointer, click and wheel events, and sends light updates back to the wand.

  4. Mac Apps

    The HUD runs in Agentic Mouse; Top starts Agent Flow. Agent Flow’s recording notifications turn the light red.

The Puck also advertises as a Bluetooth mouse, but macOS pairing stalled, so the receiver routes mouse reports over the UART link instead.

Small device-code updates go through the running receiver, so the wand doesn’t need reflashing or reconnecting. It lights red while updating.

Needs

  • Agentic Mouse ↗ Draws the HUD and runs its cards. Wand support is in Ethan’s local build and isn’t published yet.
  • Agent Flow ↗ Records and pastes dictation. The public build accepts its mouse controls; wand input isn’t published yet.
  • Espruino ↗ JavaScript firmware on the Puck.js. Public. The first upload uses the Espruino Web IDE.

Build Your Own

The repository has the device code, the bridge, the receiver source and the tests. You’ll need a Puck.js v2.1, three momentary buttons, a tube and a Mac.

Status

  • Earlier controls were tested on the wand; the latest gestures and tuning still need a physical check.
  • Held positioning clicks on release and resumes prior high sensitivity after 300 ms. Ethan confirmed the still-hand tolerance feels good.
  • End-to-end latency, accuracy and battery life haven’t been measured.
