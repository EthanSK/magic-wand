How do I dictate?

Tap Top to start Agent Flow dictation. The light turns red when nothing else is active.
Talk normally. The pointer, HUD and review all keep working while you speak.
Putting the wand down never stops dictation, so tap Top again when you're done. Agent Flow then pastes what you said.

Steps:
1. Tap Top
2. Speak
3. Tap Top to stop
4. Text is pasted
