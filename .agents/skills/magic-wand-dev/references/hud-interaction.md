## Follow mode and open HUD (2026-10-30 clarification)

Ethan: “if it's on follow mode ... should still be able to click when the HUD is open. ... I can always turn it off.” An open, unheld HUD does not suppress normal follow-mode motion or stop-to-click. Follow off still prevents ordinary pointer clicks. Keep active HUD-button adjustments and screenshot/mouse-button drag ownership distinct from merely showing the HUD. This supersedes the earlier visible-HUD stop-to-click suppression.

Normal mouse-button-held page scrolling remains a straight stroke, then continued scrolling while held. Disabling the retired circular Switch App continuation never disables this page-scroll lane. Receive the initial stroke before the existing tap/hold threshold, but emit no scroll for a short tap.
